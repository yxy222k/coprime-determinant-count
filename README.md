# 计数： $ac-bd$ 与 $n$ 互素的四元组

## 问题

设 $f = ac - bd$，其中 $a, b, c, d$ 都是 $0$ 到 $25$ 的整数（含两端）。共有多少组 $(a,b,c,d)$ 使 $\gcd(f, 26) = 1$？要求用纯排列组合的方法求解。

**答案： $157248$**。总组合数为 $26^4 = 456976$，合格的约占 $34.4\%$。

推广到模任意正整数 $n$（ $a,b,c,d$ 取遍 $0,\dots,n-1$）：

```math
N(n) = n^4 \prod_{p \mid n} \left(1 - \frac{1}{p}\right)\left(1 - \frac{1}{p^2}\right)
```

其中乘积取遍 $n$ 的所有不同素因子 $p$。 $N(n)$ 就是 $\lvert \mathrm{GL}_2(\mathbb{Z}/n\mathbb{Z}) \rvert$，即模 $n$ 下 $2\times 2$ 可逆矩阵的个数。

---

## 1. 把模 26 拆成模 2 和模 13

由于 $26 = 2 \times 13$， $\gcd(f, 26) = 1$ 等价于下面两个条件同时成立：

- $f$ 是奇数，即 $f \not\equiv 0 \pmod 2$；
- $13 \nmid f$，即 $f \not\equiv 0 \pmod{13}$。

**一一对应。** 把 $0,\dots,25$ 中的每个数 $x$ 映到数对 $(x \bmod 2,\ x \bmod 13)$。

- 如果 $x$ 和 $y$ 映到同一个数对，那么 $2 \mid x-y$ 且 $13 \mid x-y$，于是 $26 \mid x-y$。又因为 $\lvert x-y \rvert < 26$，只能 $x = y$，所以这个映射是单射。
- 两边都有 $26$ 个元素，所以它是一一对应。

因此，每个四元组 $(a,b,c,d)$ 恰好对应一个"模 2 四元组"和一个"模 13 四元组"。 $f \bmod 2$ 只取决于前者， $f \bmod 13$ 只取决于后者，两个条件互不干扰。由乘法原理：

```math
\text{总数} = N_2 \times N_{13},\qquad
N_p = \#\{(a,b,c,d) \in \{0,\dots,p-1\}^4 : ac - bd \not\equiv 0 \pmod p\}
```

## 2. 计算 $N_p$（ $p$ 为素数）：两种数法

### 方法 A：先数补集，按乘积值配对

先统计 $(a,c) \in \{0,\dots,p-1\}^2$ 的乘积 $ac$ 取各个值的方式数：

- $ac \equiv 0$： $a = 0$ 或 $c = 0$，共 $2p - 1$ 种；
- $ac \equiv k$（ $k \neq 0$）： $a$ 可以取 $1,\dots,p-1$ 中任意一个。 $p$ 是素数，所以 $a$ 可逆， $c = k a^{-1}$ 被唯一确定。因此每个非零值 $k$ 各有 $p - 1$ 种。

$ac - bd \equiv 0$ 等价于 $ac \equiv bd$，也就是 $(a,c)$ 与 $(b,d)$ 的乘积落在同一个值上：

```math
\#\{ac \equiv bd\} = \underbrace{(2p-1)^2}_{\text{同为 }0} + \underbrace{(p-1)\cdot(p-1)^2}_{p-1\text{ 个非零值}}
```

用总数减去补集：

```math
N_p = p^4 - (2p-1)^2 - (p-1)^3 = p(p-1)(p^2-1)
```

### 方法 B：直接计数，分两步选

- 先选 $(a,b)$：不能同时被 $p$ 整除，共 $p^2 - 1$ 种。如果 $a \equiv b \equiv 0$，无论 $c,d$ 怎么取， $f$ 都被 $p$ 整除。
- $(a,b)$ 定下之后， $ac - bd \equiv 0$ 是关于 $(c,d)$ 的一次方程，恰好有 $p$ 个解：
  - 若 $p \nmid a$：每选定一个 $d$，恰有一个 $c$ 满足方程，共 $p$ 个解；
  - 若 $p \mid a$：此时 $p \nmid b$，方程要求 $d \equiv 0$，而 $c$ 任意，同样是 $p$ 个解。

  所以合格的 $(c,d)$ 有 $p^2 - p$ 种。

```math
N_p = (p^2 - 1)(p^2 - p)
```

这正是 $\lvert \mathrm{GL}_2(\mathbb{F}_p) \rvert$ 的标准推法：第一行非零，第二行不在第一行张成的直线上。

### 两种方法的比较

| | 方法 A | 方法 B |
|---|---|---|
| 计数方式 | 先数补集 $ac \equiv bd$ | 直接数合格的 |
| 看待变量的方式 | $ac$、 $bd$ 对称，按乘积值分组 | 先定 $(a,b)$，把 $(c,d)$ 当一次方程的未知数 |
| 核心工具 | 乘积值的分布 | 一次方程恰有 $p$ 个解 |
| 结果的形式 | $p^4 - (2p-1)^2 - (p-1)^3$ | $(p^2-1)(p^2-p)$，乘积形式 |

方法 B 更简洁，并且能直接推广到 $k \times k$ 矩阵；方法 A 对 $a,b,c,d$ 完全对称，不需要分情况讨论。

## 3. 代入 $n = 26$

**$p = 2$：** $N_2 = 2 \cdot 1 \cdot 3 = 6$。

直接验证： $ac$ 为奇数只有 $a = c = 1$ 这 $1$ 种，为偶数有 $3$ 种。 $f$ 为奇数要求 $ac$、 $bd$ 恰好一奇一偶，共 $2 \times 1 \times 3 = 6$ 种。

**$p = 13$：**

```math
N_{13} = 13^4 - 25^2 - 12^3 = 28561 - 625 - 1728 = 26208 = 168 \times 156
```

**合并：**

```math
N(26) = N_2 \times N_{13} = 6 \times 26208 = 157248
```

如果写成方法 B 的连乘形式，就是 $6 \times 168 \times 156$。

## 4. 推广到任意 $n$

### 第一步：从 $n$ 化到无平方因子的 $r$

令 $r$ 为 $n$ 所有不同素因子的乘积，例如 $r(12) = 6$， $r(26) = 26$。

- **只有余数要紧**： $\gcd(f, n) = 1$ 等价于 $\gcd(f, r) = 1$，因为两者都是在问"有没有哪个素因子 $p$ 整除 $f$"。而 $f \bmod r$ 只取决于 $a,b,c,d$ 各自除以 $r$ 的余数。
- **每个余数类大小相同**： $0,\dots,n-1$ 按模 $r$ 分成 $r$ 个余数类，每类恰好 $n/r$ 个数。

所以先在 $0,\dots,r-1$ 里数合格的组合，再让每个变量在自己的余数类里任意替换：

```math
N(n) = \left(\frac{n}{r}\right)^4 N(r)
```

### 第二步：把 $r$ 拆成各个素数

$r = p_1 p_2 \cdots p_m$，各素数互不相同。论证与第 1 节相同： $0,\dots,r-1$ 与 $(x \bmod p_1, \dots, x \bmod p_m)$ 一一对应，而每个条件 $p_i \nmid f$ 只看模 $p_i$ 的那一份。由乘法原理：

```math
N(r) = \prod_{i=1}^{m} N_{p_i}
```

### 第三步：合起来

```math
N(n) = \left(\frac{n}{r}\right)^4 \prod_{p \mid n} p^4 \left(1 - \frac{1}{p}\right)\left(1 - \frac{1}{p^2}\right)
     = n^4 \prod_{p \mid n} \left(1 - \frac{1}{p}\right)\left(1 - \frac{1}{p^2}\right)
```

最后一步用到 $\prod_{p \mid n} p^4 = r^4$。

这个式子的结构和欧拉函数 $\varphi(n) = n \prod_{p \mid n}(1 - 1/p)$ 完全一样：先取全部 $n^4$ 种组合，每个素因子 $p$ 再乘上一个"合格比例"。 $N(n)$ 也可以写成

```math
N(n) = n \cdot \varphi(n) \cdot J_2(n),\qquad J_2(n) = n^2 \prod_{p \mid n}\left(1 - \frac{1}{p^2}\right)
```

其中 $J_2$ 是 Jordan 函数。

### 算例

- $n = 26$： $26^4 \cdot \frac{1}{2} \cdot \frac{3}{4} \cdot \frac{12}{13} \cdot \frac{168}{169} = 157248$。
- $n = 12$（含平方因子， $r = 6$）： $(12/6)^4 \cdot N_2 \cdot N_3 = 16 \cdot 6 \cdot 48 = 4608$。

### 更高维的推广

对 $k \times k$ 矩阵，"行列式与 $n$ 互素"的矩阵个数为：

```math
N_k(n) = n^{k^2} \prod_{p \mid n} \prod_{j=1}^{k}\left(1 - \frac{1}{p^j}\right)
```
